# Yessr!

**옛썰!** 현재 요청을 확인하고, 지정한 출력 형식을 지키는 로컬 Codex용 응답 규칙 플러그인입니다.

현재는 **0.1.0 실험용 구현 후보**입니다. 이전 portable manifest는 Codex CLI `0.164.0-alpha.11.1`에서 설치·활성화되었지만 후크가 발견되지 않았습니다. 해당 버전이 후크 로딩에 사용하는 단일 `.codex-plugin/plugin.json`으로 수정했습니다. 수정본의 재설치·후크 신뢰·모델 응답 연결은 아직 검증하지 않았습니다. 호환성 근거와 설치 절차는 [플러그인 README](plugins/yessr/README.md#설치와-신뢰-검토)에 있습니다.

## v1 목표

- 일반 진행 보고·질문·최종 답변은 현재 요청을 짧게 복명복창합니다. 명시적으로 생략을 요청하면 복명복창하지 않습니다.
- JSON·코드·고정 문자열 등 정확한 출력 요청에는 복명복창이나 마무리 설명을 붙이지 않습니다.
- 한국어를 유지하면서 ASD-STE100의 명료한 작성 원칙을 참고합니다. 코드·식별자·인용·조건·예외·불확실성을 보존합니다.
- 일반 자연어의 출력 요구를 보수적으로 판별합니다. 요구가 불명확하거나 상충하면 자동 수정을 요청하지 않습니다.
- 검사 가능한 위반에만 플러그인 제어기 기준으로 Codex 턴당 한 번 이하의 수정을 요청합니다. 응답 규칙의 정본은 하나만 유지합니다.

## 설계 범위와 한계

실제 상위 지침과 명시적인 출력 요청을 우선합니다. 복명복창 접두, 원시 응답 전체의 JSON 문법, 고정 문자열 일치를 검사합니다. 한국어 문체는 차단 조건으로 사용하지 않습니다. 인용·상충·조건·이전 형식이 불명확하면 자동 수정을 생략합니다.

접두 검사는 요약의 정확성을 보장하지 않습니다. 한국어 작성 원칙의 적용을 정식 ASD-STE100 준수나 인증으로 표현하지 않습니다.

Codex Stop 후크의 수정 요청은 추가 응답을 유도합니다. 이미 표시된 답변을 회수하거나 모든 진행 보고를 표시 전에 차단하지 않습니다. 수정 횟수 제한은 이 플러그인의 요청에만 적용하며, 다른 플러그인의 동작까지 통제하지 않습니다.

응답 지침의 정본은 [plugins/yessr/policy.json](plugins/yessr/policy.json)입니다. 지원 예문, 이전 형식의 보수적 처리, 정상 설치·신뢰 절차와 검증 한계는 [플러그인 README](plugins/yessr/README.md)에 있습니다.

## 로컬 검증

Node.js 24에서 저장소 루트 기준으로 실행합니다. 추가 패키지 설치나 빌드 단계는 없습니다.

```sh
node --test tests/yessr.test.mjs
```

단위·프로세스 시험은 실제 활성 플러그인 동작의 증거가 아닙니다. 호스트의 후속 목표 변경, 재개·압축, 수정 후속 턴 연결은 정상 설치와 신뢰 후 별도로 검증해야 합니다.
